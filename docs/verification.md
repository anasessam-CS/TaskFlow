# نتائج الفحص الأولي

التاريخ 24 نوفمبر 2026. الفحوصات استخدمت PHP 8.4، وChromium، وJava 21 مع Maven وJUnit 5.

| الفحص | النتيجة |
| --- | --- |
| قواعد PHP وJavaScript | كل ملفات PHP اجتازت `php -l` وملف JavaScript اجتاز `node --check`. |
| HTTP على التطبيق الأصلي | فتح اللوحة من غير جلسة أعاد التوجيه بـ 303. POST من غير CSRF رُفض بـ 403. GET لتسجيل الخروج رُفض بـ 405. مسار الإعداد في خادم PHP المدمج أعاد صفحة الدخول العامة. |
| Selenium على التطبيق الأصلي بدون إعداد Supabase | 4 اختبارات نجحت و5 تخطّاها JUnit لأنها تحتاج حسابًا صالحًا. |
| Selenium مع بديل محلي لـ Supabase | 9 اختبارات نجحت، منها الدخول والخروج وإضافة المهمة وتعديلها وإكمالها وحذفها. البديل استُخدم في نسخة اختبار منفصلة. |
| PostgreSQL محلي باستخدام PGlite | إنشاء المخطط وسياسات RLS نجح. اختبرنا القراءة والتعديل والحذف بحساب آخر، ورفض تغيير معرّف المالك عبر الإدراج، ورفض الحالة غير الصالحة والعنوان الفارغ. |
| Supabase مباشر | ينتظر إعداد مشروع اختبار. يلزم التحقق من تسجيل حساب جديد، وتأكيد البريد، وتكرار التسجيل، والاتصال من PHP، وعزل حسابين في المشروع الفعلي. |

تنبيه CDP ظهر لأن إصدار Chromium أحدث من إصدارات DevTools المضمنة في Selenium. اختبارات WebDriver المبيّنة أعلاه اكتملت. احتفظ بتقرير Maven عند إعادة التشغيل على Supabase الفعلي واملأ عمود النتيجة في `manual-tests.md`.
